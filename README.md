# meeting-notes-data-demo

[Meeting Notes](https://github.com/IUT-b/meeting-notes) が保存する議事録のサンプルです。
内容はすべて架空の会議で、実在の会社・人物とは関係ありません。

## ファイルの形

- 1会議が1つの Markdown ファイルです。フォルダは、アプリで整理したフォルダがそのままディレクトリになります。
- 本文は人が読むための議事録です。GitHub でそのまま読めます。
- ファイルの末尾に、会議どうしのつながり・決定事項・ToDo などのメタ情報がコメントとして入っています。
  整形表示では見えません。見るには、ファイルを開いて「Code」表示に切り替えてください。

アプリを使うのをやめても、このリポジトリはそのまま残ります。
